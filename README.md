# Inovação Tecnológica no Manejo Apícola

Aplicativo mobile voltado ao **registro, organização e gerenciamento de informações de apiários**, com foco em **funcionamento offline**, simplicidade de uso e confiabilidade dos dados.

Este projeto está inserido no contexto de **Inovação Tecnológica no Manejo Apícola**, buscando aplicar soluções tecnológicas para otimizar práticas do setor apícola.

---

## 1. Público-Alvo

- Apicultores
- Estudantes da área de agropecuária
- Projetos acadêmicos e de extensão
- Pesquisadores da área apícola

---

## 2. Descrição do Projeto

O Manejo Apícola Inteligente tem como objetivo auxiliar apicultores no controle das atividades realizadas nos apiários, permitindo o registro de dados essenciais de forma estruturada e acessível, mesmo em ambientes sem acesso à internet.

O sistema foi projetado para uso em campo, considerando as limitações de conectividade e a necessidade de registros rápidos e confiáveis.

---

## 3. Objetivos

- Facilitar o registro de informações relacionadas ao manejo apícola
- Reduzir perdas de dados causadas por anotações manuais
- Possibilitar o acompanhamento histórico das atividades do apiário
- Oferecer uma solução digital funcional em modo offline

---

## 4. Funcionalidades

- Cadastro de apiários
- Anotações de atividades de manejo
- Histórico de registros
- Armazenamento local de dados
- Funcionamento integral sem necessidade de conexão com a internet

---

## 5. Tecnologias Utilizadas

- React Native + Expo
- Android (Android First)
- SQLite (Expo SQLite)
- Speech-to-Text nativo do Android
- Inteligência Artificial (Cloud)

As tecnologias foram selecionadas visando desempenho, simplicidade de manutenção e compatibilidade com dispositivos móveis Android.
